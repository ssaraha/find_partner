DESCRIPTION

- Ce projet permet de faire une demande de réalisation des projets des differents categories(IT - commerce - Btp - etc) à une sociéte qui peut travailler dans des catégories dediés.

- Primo un utilisateur doit avoir un compte entant que client  ou sociéte.
- Un client crée un projet et puis envoie une demande de réalisation à un company.
- Et puis la société est informé via un email, puis il peut accepté la réalisation.
- Durant la réalisation on puis suivre l'évolution de la réalisation via un status en pourcentage.

FICHE TECHNIQUE et TECHNOLIGIES:

BACKEND: nodejs - express
FRONTEND: Tailwindcss v4 - Reactjs : Zustand pour la gestion des etats - reactformik pour gerer les formulaire ...
